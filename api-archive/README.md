# Самый простой архиватор

## быстрый старт
запуск
`go run .`

дергать ручки через 
`curl http://localhost:8080/ping`


## для разработки
короткая дока
https://go.dev/doc/tutorial/web-service-gin

`go mod init example/web-service-gin`

для получения зависимостей
`go get .`
форматирование
`gofmt -w .`
тесты
`go test -v ./internal`

запуск
`go run .`

дергать ручки через 
`curl http://localhost:8080/ping`
