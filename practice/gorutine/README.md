О, классная тема 👍 Если хочешь реально прокачать горутины и конкурентность в Go, вот подборка задач — от базовых до почти «боевых». Все они часто всплывают на собесах и в реальных проектах.

⸻

🟢 Базовый уровень (чтобы почувствовать горутины)

1. Простые горутины
 • Запусти 5 горутин, каждая печатает свой номер
 • Дождись завершения всех (через sync.WaitGroup)

👉 Что тренирует: go, WaitGroup

⸻

2. Горутина + канал
 • Одна горутина отправляет числа 1–10 в канал
 • Другая их читает и выводит
 • Корректно закрыть канал

👉 Что тренирует: chan, close, range

⸻

3. Fan-in, fan-out
 • Есть 3 горутины-производителя
 • Каждая пишет в свой канал
 • Объедини всё в один общий канал

👉 Очень частый паттерн

⸻

🟡 Средний уровень (то, что спрашивают чаще всего)

4. Worker Pool (must-have)
 • Есть:
 • очередь задач
 • N воркеров
 • Каждый воркер обрабатывает задачу
 • После обработки результат отправляется в канал результатов

Усложнение:
 • динамическое количество воркеров
 • graceful shutdown

👉 Это ТОП-1 задача на горутины

⸻

5. Ограничение параллелизма
 • Есть 100 задач
 • Выполнять не больше 5 одновременно

Подсказка:
 • буферизированный канал
 • или semaphore через chan struct{}

👉 Очень практично для API / БД

⸻

6. Pipeline

Стадии:
 1. Генерация чисел
 2. Возведение в квадрат
 3. Фильтр (оставить чётные)
 4. Вывод

Каждая стадия — своя горутина + канал

👉 Классика Go

⸻

🔴 Продвинутый уровень (для уверенного Go-разработчика)

7. Context + cancel
 • Запусти несколько воркеров
 • Через context.WithCancel останови их всех
 • Все горутины должны корректно завершиться

👉 Без этого сейчас никуда

⸻

8. Timeout
 • Задача может выполняться долго
 • Если она работает > 2 секунд — отменяем

Использовать:
 • context.WithTimeout
 • select

⸻

9. Rate Limiter
 • Можно выполнять не более:
 • 10 запросов в секунду
 • Реализовать через time.Ticker + канал

👉 Часто нужно для внешних API

⸻

10. Graceful shutdown
 • Есть сервер/воркеры
 • При SIGINT:
 • новые задачи не принимаются
 • текущие корректно завершаются

👉 Прямо «продакшен»

⸻

🧠 Челленджи

11. Deadlock challenge
 • Намеренно создай deadlock
 • Потом исправь его
 • Объясни, почему он произошёл

⸻

12. Data race
 • Есть общая переменная
 • Несколько горутин её меняют
 • Исправить через:
 • mutex
 • или каналы

👉 Запусти с -race

⸻

💡 Как тренироваться эффективно
 1. Делай без подсказок
 2. Потом сравнивай с эталонами
 3. Объясняй вслух, что происходит
 4. Запускай go test -race
